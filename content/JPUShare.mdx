JPUShare는 연구실 구성원이 GPU 서버를 함께 쓰며 학습 작업을 실행하고 결과를 확인하는 서비스입니다. 웹에서 데이터와 코드를 준비하고, 실행 환경과 GPU 서버를 골라 작업을 제출합니다.

[JPUShare 접속하기](https://share.jedutools.io)

처음 사용한다면 **회원가입 → 이메일 인증 → 참가 코드로 연구실 참가 신청 → 책임교수 또는 연구실 관리자 승인** 순서로 준비합니다. 승인이 끝나면 **데이터 준비 → 작업 제출 → 결과 확인** 순서로 사용합니다.

## 1. 사용 방법

JPUShare는 두 가지 방법으로 사용할 수 있습니다. 연구실 참가와 승인은 어느 쪽이든 웹에서 먼저 마칩니다.

| 방법 | 이런 경우에 | 문서 |
|---|---|---|
| [웹으로 사용하기](/JPUShare/1Web) | 웹 화면에서 직접 데이터를 올리고 작업을 제출합니다. | [시작하기](/JPUShare/1Web/1GettingStarted), [데이터 관리](/JPUShare/1Web/2Datasets), [학습 작업 실행](/JPUShare/1Web/3Jobs), [결과 확인과 다운로드](/JPUShare/1Web/4Results), [문제 해결](/JPUShare/1Web/5Troubleshooting) |
| [AI 에이전트로 사용하기](/JPUShare/2Agent) | Claude Code 같은 AI 에이전트나 직접 만든 프로그램에게 작업 제출과 결과 받기를 맡깁니다. | [에이전트 연결하기](/JPUShare/2Agent/1Connect), [API 사용법](/JPUShare/2Agent/2API) |

## 2. 주요 용어

| 용어 | 의미 |
|---|---|
| 연구실 | 구성원과 저장 공간을 묶어 관리하는 단위입니다. 책임교수 또는 연구실 관리자가 참가를 승인합니다. |
| 참가 코드 | 연구실에 참가 신청할 때 입력하는 숫자 5자리입니다. 책임교수 또는 연구실 관리자에게 받습니다. |
| 연구실 공유 / 내 폴더 | 연구실 구성원이 함께 보는 저장 공간과 나만 보는 저장 공간입니다. |
| 실행 환경 | Python과 학습 라이브러리가 들어 있는 실행 이미지입니다. |
| 작업 | 실행 명령과 입력 데이터, GPU 서버를 지정해 제출한 실행 요청입니다. |
| 결과 파일 | 작업이 `/output` 아래에 저장해 회수된 모델, 지표, 로그 등의 파일입니다. |

## 3. 첫 작업 전에 확인할 것

1. 로그인 후 소속 연구실이 올바르게 표시되는지 확인합니다.
2. 실행할 코드와 코드가 읽는 데이터를 준비합니다.
3. 고른 GPU 서버에서 돌 수 있는 실행 환경인지 확인합니다. 돌지 않는 환경은 작업 제출 화면에서 선택할 수 없습니다.
4. 프로그램이 결과 파일을 `/output` 아래에 저장하는지 확인합니다.
5. 처음에는 짧게 실행해 입력 경로, 실행 명령, 결과 저장을 확인한 뒤 본 학습을 진행합니다.

사용할 수 있는 GPU 서버, 실행 환경, 저장 용량은 연구실과 운영 설정에 따라 다릅니다. 화면에 표시되는 값이 기준입니다.
