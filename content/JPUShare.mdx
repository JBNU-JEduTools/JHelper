## 연구실 GPU로 학습 작업 실행하기

JPUShare는 연구실 구성원이 GPU 자원을 함께 사용하며 학습 작업을 실행하고 결과를 확인하는 서비스입니다. 웹에서 데이터와 코드를 준비하고, 실행 환경과 필요한 자원을 선택해 작업을 제출할 수 있습니다.

[JPUShare 접속하기](https://share.jedutools.io)

처음 사용한다면 **로그인과 연구실 확인 → 데이터 준비 → 작업 제출 → 결과 확인** 순서로 진행합니다.

## 주요 용어

| 용어 | 의미 |
|---|---|
| 연구실 | 구성원과 사용 가능한 자원을 묶어 관리하는 단위 |
| 데이터셋 | 작업에서 사용할 데이터와 코드 파일을 준비하는 저장 영역 |
| 실행 환경 | Python과 학습 라이브러리 등 프로그램 실행에 필요한 환경 |
| 작업 | 실행 명령과 입력 데이터, 자원 조건을 지정해 제출한 실행 요청 |
| 결과 파일 | 작업에서 생성해 결과 경로에 저장한 모델, 예측값, 보고서 등의 파일 |

## 첫 작업 전에 확인할 것

1. 로그인 후 소속 연구실이 올바르게 표시되는지 확인합니다.
2. 실행할 코드뿐 아니라 코드가 읽는 데이터와 필요한 보조 파일도 준비합니다.
3. 선택한 실행 환경에 필요한 라이브러리가 포함되어 있는지 확인합니다.
4. 프로그램이 결과 파일을 어디에 저장하는지 확인합니다. 작업 중 임의의 경로에 만든 파일이 모두 다운로드 대상으로 남는 것은 아닙니다.
5. 처음에는 짧은 실행으로 입력 경로, 실행 명령, 결과 저장을 확인한 뒤 본 학습을 진행합니다.

사용 가능한 GPU, 실행 환경, 저장 용량과 보관 기간은 연구실 및 운영 설정에 따라 다릅니다. 현재 화면에 표시되는 값과 소속 연구실의 안내를 확인하세요.

*가이드의 화면은 2026년 9월 16일 운영 사이트에서 캡처했습니다. 작업 이름·파일 목록·사용량은 촬영 당시의 예시이며, 계정과 운영 상황에 따라 달라집니다.*
