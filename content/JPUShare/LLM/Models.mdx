JPUShare LLM은 연구실 GPU 서버를 연구 작업과 함께 씁니다. 모델을 고르는 법, 모델이 잠시 멈추는 때, 오류가 났을 때 할 일을 정리했습니다.

## 1. 쓸 수 있는 모델

제공하는 모델은 다음과 같습니다. 최신 목록은 [연결 확인](/JPUShare/3LLM/1Start)의 `GET /v1/llm/models`로 봅니다.

| 모델 이름 | 크기 | 참고 |
|---|---|---|
| `auto` | — | 지금 떠 있는 모델 가운데 하나가 답합니다. 특별한 이유가 없으면 이것을 씁니다. |
| `qwen3.6-35b-a3b` | 35B | `auto`로 보내면 보통 이 모델이 답합니다. |
| `gemma-4-31b` | 31B | |
| `qwen3.8-27b` | 27B | |
| `qwen3.8-flash-next` | 125B | |
| `deepseek-v4-flash` | 284B | |

B는 10억 개(매개변수 수)입니다.

모델 이름은 `model`에 그대로 적습니다. 없는 이름을 보내면 404 `LLM_MODEL_UNKNOWN`과 함께 쓸 수 있는 이름 목록이 옵니다.

## 2. 모델을 쓸 수 있는 때

LLM은 GPU 서버가 비어 있을 때 그 서버에서 돕니다. 연구 작업이 들어오면 그 서버의 모델은 곧 자리를 비켜 주고, 작업이 끝나면 다시 올라옵니다. 그래서 모델마다 쓸 수 있는 때가 다릅니다.

- 이름을 정해 부른 모델이 쉬는 중이면 503 `LLM_MODEL_UNAVAILABLE`(「모델 서버가 지금 떠 있지 않습니다.」)이 옵니다. `model`을 `auto`로 바꾸거나, 다른 모델을 고르거나, 잠시 뒤 다시 보냅니다. 이미 `auto`로 보냈는데 503이면 지금 떠 있는 모델이 없는 것이니 잠시 뒤 다시 보냅니다.
- 모델 목록은 제공하는 이름의 목록입니다. 지금 떠 있는지는 실제로 요청을 보내 봐야 압니다.
- 연구 작업이 우선입니다. 오래 걸리는 일괄 처리는 중간에 503이 와도 이어서 다시 보낼 수 있게 만듭니다.

## 3. 생각 모드

모델에 따라 생각(추론) 모드가 기본으로 켜져 있어, 답 앞에 생각을 먼저 만듭니다. 생각은 `choices[0].message.reasoning_content`에 따로 오고, 그만큼 시간이 걸리고 `max_tokens`를 씁니다.

| 원하는 것 | 요청에 넣을 것 |
|---|---|
| 짧고 빠른 답 | `"chat_template_kwargs": {"enable_thinking": false}` |
| 어려운 문제를 깊게 | 생각을 켠 채로 두고 `max_tokens`를 넉넉히 줍니다(예: 4096 이상). |

`max_tokens`가 작은데 생각을 켜 두면, 생각만 하다가 `finish_reason`이 `length`로 끝나고 본문(`content`)이 비어 있을 수 있습니다.

## 4. 오류와 대처

| 응답 | 뜻 | 대처 |
|---|---|---|
| 401 `UNAUTHORIZED` | 키가 틀렸거나 폐기·만료되었습니다. | 키 원문을 확인하고, 필요하면 새로 발급합니다. |
| 403 `API_KEY_SCOPE_REQUIRED` | 키에 **LLM 사용**(`llm:invoke`)이 없습니다. | [시작하기](/JPUShare/3LLM/1Start) 2절대로 켭니다. |
| 403 `JWT_REQUIRED` | 예전 방식(v1) 키입니다. | 새 키를 발급합니다. |
| 403 `LLM_LAB_REQUIRED` | 연구실 구성원이 아닙니다. | 연구실 참가 승인을 받습니다. |
| 400 `LLM_MODEL_REQUIRED` | `model`이 비어 있고 기본 모델도 없습니다. | `auto`나 모델 이름을 넣습니다. |
| 404 `LLM_MODEL_UNKNOWN` | 제공하지 않는 모델 이름입니다. | 응답의 `models` 목록에서 고릅니다. |
| 429 | 요청이 너무 잦습니다. | 잠시 뒤 다시 보냅니다. |
| 503 `LLM_MODEL_UNAVAILABLE` | 그 모델이 지금 떠 있지 않습니다(연구 작업에 자리를 비켰거나 올라오는 중). | `auto`, 다른 모델, 잠시 뒤 다시 보내기 가운데 하나를 고릅니다. |
| 502 `LLM_UPSTREAM_REJECTED` | LLM 서버 설정 문제입니다. | 운영자에게 알립니다. |
| 503 `LLM_DISABLED` | LLM 서비스가 꺼져 있습니다. | 운영자에게 문의합니다. |
