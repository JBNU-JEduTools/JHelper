JPUShare에서 코드와 데이터를 제출하고 GPU 작업의 상태, 로그, 결과를 확인할 수 있습니다.
처음 이용하는 경우 계정과 연구실 참가 코드를 준비합니다. 계정 발급과 참가 코드는 연구실 담당자에게 문의합니다.

## 1. 서비스에 로그인하기

![JPUShare 로그인 화면](./images/login-form.png)

1. [JPUShare 열기](https://share.jedutools.io)를 선택합니다.
2. **아이디 또는 이메일**, **비밀번호**를 입력하고 **로그인** 버튼을 클릭합니다.
3. JPUShare로 돌아온 뒤 연구실 참가 화면 또는 작업 화면이 열리는지 확인합니다.

로그인에 실패한 경우 **다시 로그인**을 클릭합니다.
반복해서 실패하면 [문제 해결](/JPUShare/6Troubleshooting)을 참고합니다.

## 2. 연구실 참가 신청하기

이미 연구실에 소속되어 있다면 이 단계는 건너뜁니다.

1. **연구실 참가** 화면의 **참가 코드**에 숫자 5자리를 입력합니다.
2. **신청**을 선택합니다.
3. **승인 대기 중** 표시와 연구실 이름을 확인합니다.
4. 담당자에게 승인을 요청한 뒤 **다시 조회**로 상태를 확인합니다.

신청 직후에는 승인 대기 상태입니다. 승인되기 전에는 데이터셋과 작업 화면을 이용할 수 없습니다.
잘못된 연구실에 신청했다면 **신청 취소** 후 올바른 코드로 다시 신청하세요.

**계정 정보 미비**가 표시되면 화면의 **계정 관리** 링크에서 안내된 정보를 보완합니다.
재시도 대기 시간이 표시되면 해당 시간이 지난 뒤 신청하세요.
참가 코드는 공개 문서나 저장소에 올리지 않습니다.

## 3. 사용할 화면 확인하기

![내 작업·새 작업·데이터셋·실행 환경·GPU 서버 메뉴](./images/main-navigation.png)

| 화면 | 할 수 있는 일 |
| --- | --- |
| 내 작업 | 제출한 작업을 찾고 상태와 상세 정보를 확인합니다. |
| 새 작업 | 코드, GPU 서버, 입력 데이터, 실행 명령을 지정합니다. |
| 데이터셋 | 접근 가능한 저장소의 파일을 올리고 내려받습니다. |
| 실행 환경 | 배포된 환경의 이름과 설명을 확인합니다. |
| GPU 서버 | 현재 GPU 구성과 사용 상태를 확인합니다. |

화면에 표시되는 서버와 환경은 운영 상황에 따라 달라질 수 있습니다.
필요한 라이브러리와 GPU 메모리를 먼저 확인하고 현재 선택 가능한 항목을 사용하세요.

## 4. 첫 작업 준비하기

![실행 환경별 Python, 프레임워크와 CUDA 버전](./images/environments.png)

1. **실행 환경**에서 코드에 필요한 Python과 라이브러리가 포함된 환경을 확인합니다.
2. **GPU 서버**에서 GPU 모델과 메모리, 대기 상태를 살펴봅니다.
3. 입력 데이터가 있다면 **데이터셋**에 먼저 업로드합니다.
4. 코드를 ZIP으로 준비하거나 공개 Git 저장소 주소와 ref를 확인합니다.
5. [학습 작업 실행](/JPUShare/3Jobs)의 작은 Python 예제로 제출 흐름을 확인합니다.

새 환경이 필요하거나 패키지 지원 여부를 판단하기 어렵다면 연구실 담당자에게 문의합니다.
ZIP에 패키지 목록 파일을 넣는 것만으로 의존성이 자동 설치되는 것은 아닙니다.

## 5. 저장 위치 확인하기

| 위치 | 용도 |
| --- | --- |
| 데이터셋 저장소 | 다음 작업에서도 사용할 입력 파일을 보관합니다. |
| 실행 중 작업 공간 | 코드를 풀고 계산하는 임시 공간입니다. |
| 결과 저장소 | 작업에서 회수한 출력 파일을 확인하는 곳입니다. |

작업 공간에만 만든 파일은 결과로 남지 않을 수 있습니다.
보관할 파일은 코드에서 지정된 출력 경로에 저장하고, 작업 종료 후 다운로드까지 확인하세요.
경로 예시는 [학습 작업 실행](/JPUShare/3Jobs)에 있습니다.

## 관련 문서

- 로그인이 반복되거나 승인이 반영되지 않으면 [문제 해결](/JPUShare/6Troubleshooting)을 확인합니다.
- 저장소가 보이지 않으면 연구실 소속과 저장소 준비 상태를 담당자에게 확인합니다.
- 파일 준비는 [데이터셋 관리](/JPUShare/2Datasets), 실행 후 확인은 [결과 확인과 다운로드](/JPUShare/4Results)를 참고합니다.
- 프로그램에서 이용하려면 [API 사용법](/JPUShare/5API)을 참고합니다.
