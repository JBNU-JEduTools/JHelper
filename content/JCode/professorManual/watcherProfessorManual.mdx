## 3. 과제 관리

![image.png](./images/watcher/3.png)

![새 과제 추가 화면](./images/watcher/add-assignment.png)

### 3-1. 과제 추가 방법
- **과제 개수**
  - 기존 hw1~hw10 제한 없이, 수업에 필요한 만큼 과제 생성 가능
  - 학생은 각 과제에 할당된 별도의 과제 폴더에서 과제 수행

- **과제명**: 과제의 이름 입력

- **과제 설명 (선택)**: 과제의 내용, 수행 방법 및 요구사항 입력

- **스타터 코드 (선택)**
  - 학생이 과제를 시작할 때 사용할 기본 소스 코드 및 보조 파일
  - **스타터 코드 업로드** 버튼을 클릭하여 준비한 파일을 `.zip` 형식으로 업로드
  - 학생이 해당 과제의 작업공간에서 과제를 시작하면, 업로드한 파일들이 해당 과제 디렉토리에 제공됨
  - 예: 함수의 기본 틀, 예제 코드, 실습에 필요한 파일 등
  - 학생은 제공된 파일을 바탕으로 코드를 작성하거나 수정하여 과제 수행

- **일정**: 시작 일시와 마감 일시 설정

## 4. 전체 통계 분석

![image.png](./images/watcher/5.png)

![image.png](./images/watcher/6.png)

### 4-1. 기능 개요
- **목적**: 선택한 기간 동안 전체 학생들의 코드 변화량 확인

### 4-2. 사용 방법
- **기간 설정**
  - 시작/종료 범위: 과제 시작일과 마감일 기준
  - 슬라이더 또는 날짜 직접 선택 가능
  - 설정 후 **조회** 버튼을 클릭하여 차트 갱신
  
- **검색 및 정렬**
  - 왼쪽 위 버튼: 이름, 변화량, 학번 순 정렬
  - 오른쪽 위 검색창: 이름 또는 학번으로 검색

### 4-3. 데이터 수집 방식
- 과제 단위로 수집 (예: 선택한 과제의 전체 학생 데이터)
- 해당 **과제 폴더** 내 `.c`, `.h`, `.cpp`, `.hpp`, `.py`, `.ipynb` 파일의 전체 변화량 합계
- **내 작업공간**: 일반 작업공간으로, Watcher 데이터 수집 대상에서 제외
  - 수집 대상 확장자의 파일이라도 **내 작업공간**에 저장한 경우 수집되지 않음

## 6. 개인 세부 통계(Watcher)

![image.png](./images/watcher/8.png)

### 6-1. 수집 정보
- 해당 **과제 폴더** 내 `.c`, `.h`, `.cpp`, `.hpp`, `.py`, `.ipynb` 파일의 총 코드량 및 변화량
- 과제 수행 중 빌드, 실행에 대한 로그 수집
- 이미지, PDF, 실행 파일 등은 파일 수집 대상에서 제외
  - 실행 파일 자체는 수집하지 않으며, 과제 수행 중 빌드 및 실행 기록은 로그로 수집
- **내 작업공간**에서의 활동은 Watcher 데이터 수집 대상에서 제외

### 6-2. 빌드 및 실행 로그 확인

![image.png](./images/watcher/9.png)

- 빌드/실행이 짧은 시간에 집중된 경우 겹쳐 표시될 수 있으므로 확대하여 세밀하게 확인
- 영역 클릭 시 세부 로그 확인 가능

### 6-3. 실행 로그 상세 정보

![image.png](./images/watcher/10.png)

- **기본 정보**
  - 상태: 성공 또는 실패
  - 시간 정보
  - 프로세스 유형: 바이너리 실행 파일(./example) 또는 Python 실행
  
- **경로 정보**
  - 작업 디렉토리
  - 실제 실행된 파일
  
- **명령어**
  - 사용자가 실제로 입력한 명령어

### 6-4. 빌드 로그 상세 정보

![image.png](./images/watcher/11.png)

- **기본 정보**
